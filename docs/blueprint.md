# **App Name**: SaaS Forge

## Core Features:

- Landing Page: Landing page to showcase SaaS Forge's features and benefits, with clear CTAs and plan comparisons.
- User Dashboard: User-friendly dashboard for profile management, account settings, and subscription overview.
- Authentication: Secure authentication system with email/password and OAuth (Google, GitHub) using Supabase.
- Subscription Billing: Stripe integration for subscription billing, payment processing, and subscription status management.
- UI/UX Analyzer: AI-powered tool for suggesting UI/UX improvements based on user behavior, recommending changes to increase user engagement.
- Analytics Dashboard: Basic analytics dashboard to track user sign-ups, active users, and subscription metrics.

## Style Guidelines:

- Primary color: Vibrant blue (#29ABE2) to convey trust and innovation.
- Background color: Light gray (#F5F7FA), a very desaturated tone of blue, to provide a clean, professional feel.
- Accent color: Yellow-green (#90EE90) to highlight key actions and information, providing contrast to the primary blue.
- Font pairing: 'Space Grotesk' (sans-serif) for headers and 'Inter' (sans-serif) for body text, creating a balance of modern and readable design.
- Clean, modern layout with clear sections and intuitive navigation. Focus on readability and ease of use.
- Simple, consistent icons for navigation and actions, providing visual cues and enhancing user experience.
- Subtle animations for transitions and interactions, adding a layer of polish without overwhelming the user.
